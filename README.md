## Getting Started

No build tools or dependencies are required. Open any project's `index.html` file directly in a browser, or start a local server from the project root:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000` and open a project folder.

## Project Structure

Each project is self-contained:

```text
project-name/
├── index.html
├── script.js
└── style.css
```
